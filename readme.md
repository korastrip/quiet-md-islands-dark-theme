# Islands Dark for Quiet.md

An inspired theme by Islands Dark by Jetbrains.

## How to install

```bash
git clone https://github.com/korastrip/quiet-md-islands-dark-theme.git
```

**on macOs**

```bash
cp islands-dark.css $USER/Documents/Quiet.md/.quiet/themes
```

Open Quiet.md, in the settings > appearance, choose dark and select islands dark in theme.
